Alur Model SPK
Tentang SES
Ŷ(t+1) = α·Y(t) + (1−α)·Ŷ(t)
  • α → 1: Lebih condong ke data terbaru
  • α → 0: Lebih konservatif / stabil
  • α = 0.6: Default model ini

Step 3

Simple Exponential Smoothing — Forecast FY2026

Memproyeksikan rasio profitabilitas periode FY2026 menggunakan metode SES.

Rumus SES
Ŷ(FY2026) = α · Y(FY2025) + (1 − α) · Y(FY2024)
α = 0.60
Rasio Y(FY2024) = Ŷ(t) Y(FY2025) = Y(t) α × Y(FY2025) (1−α) × Y(FY2024) Ŷ(FY2026) Δ FY25→26
